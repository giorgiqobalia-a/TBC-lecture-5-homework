1. რომელი AI ინსტრუმენტი გამოიყენე? (ChatGPT / Claude / Gemini / სხვა)

2. ჩააკოპირე ზუსტი Prompts (მოთხოვნები), რაც გაუგზავნე AI-ს:

პრომპტი 1 (HTML/დიზაინისთვის):
შექმენი სუფთა და თანამედროვე ერთგვერდიანი ვებ-აპლიკაციის index.html ფაილი Tailwind CSS CDN-ის გამოყენებით. თემაა: მინი ვიქტორინა / ქვიზი (Mini Trivia Quiz). გვერდზე უნდა იყოს: სათაური, ქულების პანელი, ბარათი კითხვისა და სავარაუდო პასუხებისთვის, ღილაკი 'შემდეგი კითხვა' და საბოლოო შედეგის ეკრანი 'თავიდან დაწყების' ღილაკით. სტილი იყოს Dark Mode (slate-900 ფონით). JavaScript კოდი ცალკე script.js ფაილში უნდა იყოს გამოტანილი.

პრომპტი 2 (JavaScript ლოგიკისთვის):
ახლა დამიწერე ამ პროექტისთვის script.js ფაილი. კოდმა უნდა გააკეთოს შემდეგი:
- fetch() და async/await-ით წამოიღოს მონაცემები უფასო საჯარო API-დან (Open Trivia Database).
- DOM მანიპულაციით (textContent, createElement, appendChild) განაახლოს ეკრანი და გამოიტანოს კითხვები და პასუხები.
- ღილაკებზე იყოს addEventListener-ები პასუხის ასარჩევად და შემდეგ კითხვაზე გადასასვლელად.
- ჰქონდეს try/catch ბლოკი შეცდომების დასაჭერად. დამიწერე კოდი დეტალური ქართული კომენტარებით.

პრომპტი 3 (კოდის ახსნისთვის - Code Explainer):
ამიხსენი script.js კოდი მარტივი, ადამიანური ენით და ანალოგიებით: რას აკეთებს async და await, რატომ გვჭირდება response.json() და როგორ მუშაობს createElement და appendChild ეკრანზე ახალი ღილაკების დასამატებლად.


-------------------------------------------------------------------
3. რა აგიხსნა AI-მ "ადამიანურ ენაზე"? (ჩაწერე შენი სიტყვებით 2-3 წინადადება, თუ რა გაიგე ახალი JavaScript-ის მუშაობის შესახებ):

პასუხი:
გავიგე, რომ async/await საშუალებას აძლევს კოდს მშვიდად დაელოდოს ინტერნეტიდან (API-დან) პასუხის მოსვლას ისე, რომ მთელი ვებგვერდი არ გაიჭედოს, ხოლო response.json() მოსულ ნედლ მონაცემებს გასაგებ JavaScript ობიექტად თარგმნის. ასევე ვისწავლე, რომ createElement-ით მეხსიერებაში ვქმნით ახალ HTML ელემენტებს (მაგალითად, პასუხის ღილაკებს), ხოლო appendChild-ით ისინი რეალურად გამოგვაქვს ეკრანზე.


-------------------------------------------------------------------
4. წააწყდი თუ არა რაიმე შეცდომას (Bug) და როგორ დაგეხმარა AI მის გამოსწორებაში?

პასუხი:
კოდის გაშვებისას შევამჩნიე, რომ API-დან წამოღებულ კითხვებსა და პასუხებში ბრჭყალებისა და აპოსტროფების ნაცვლად უცნაური HTML კოდები (მაგალითად, &quot; ან &#039;) ჩანდა. AI-ს დახმარებით დავამატეთ სპეციალური დამხმარე ფუნქცია (decodeHTML), რომელმაც ეს სიმბოლოები ავტომატურად გადათარგმნა სუფთა ტექსტად.
